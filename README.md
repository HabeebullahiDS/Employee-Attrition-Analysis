# Employee Attrition Analysis

## Project Overview
This project analyzes employee attrition using exploratory data analysis (EDA) to identify workforce patterns and factors associated with employee turnover. The analysis provides business insights that can support Human Resource (HR) decision-making and serves as a foundation for future predictive modelling.

## Objectives
- Understand the workforce composition.
- Explore employee attrition patterns.
- Identify variables associated with attrition.
- Generate business insights and recommendations.
- Prepare the dataset for future machine learning models.

## Dataset
- **Dataset:** IBM HR Employee Attrition Dataset
- **Total Records:** 1,470 employees
- **Target Variable:** Attrition (Yes/No)

## Tools and Libraries
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Exploratory Data Analysis
The analysis includes:
- Department distribution
- Job role distribution
- Overtime distribution
- Age distribution
- Monthly income distribution
- Department vs Attrition
- Job Role vs Attrition
- Overtime vs Attrition
- Age vs Attrition
- Monthly Income vs Attrition

## Key Findings
- Research & Development is the largest department.
- Sales Representatives have the highest attrition rate.
- Employees working overtime are more likely to leave.
- Younger employees tend to have higher attrition.
- Lower monthly income is associated with higher employee turnover.

## Future Work
The findings from this analysis can be used to develop predictive machine learning models for employee attrition using algorithms such as Logistic Regression, Decision Trees, Random Forests, and Gradient Boosting.
